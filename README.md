# TuneBar

Виджет «Сейчас играет» на панели задач Windows 11.

```
[ ⏮ ]  [обложка]  [ ⏭ ]  Название трека
                         Исполнитель
```

## Возможности

- Показывает трек из любого плеера, который сообщает о себе Windows: Spotify, Яндекс Музыка, SoundCloud, YouTube, VK в браузере и т.д.
- Музыкальные приложения важнее браузера: если одновременно открыты Spotify и YouTube, виджет показывает Spotify.
- Наведение на обложку — иконка плей / пауза, клик — пауза / продолжить.
- `Ctrl + →` — следующий трек, `Ctrl + ←` — предыдущий.
- Три положения на панели задач: слева, перед значками, справа у трея, плюс отступ в пикселях.
- Текст трека можно скрыть или поставить слева от кнопок.
- Скрывается, когда ничего не играет или открыто полноэкранное приложение.
- Подстраивается под светлую и тёмную тему панели задач.

## Установка

1. Установите [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64), если его ещё нет.
2. Скачайте `TuneBar.zip` из [Releases](../../releases) и распакуйте в любую папку.
3. Запустите `TuneBar.exe`.

## Настройка

`TuneBar.exe` открывает консоль управления. Навигация стрелками ↑↓, выбор — Enter, назад — Esc.

```
1 - Включить        : вкл / выкл
2 - Автозагрузка    : вкл / выкл
3 - Положение       : слева / перед значками / справа, у трея + отступ
4 - Трек и артист   : вкл / выкл
5 - Место текста    : справа / слева от кнопок
```

Изменения применяются сразу, без перезапуска виджета. Консоль также открывается из меню иконки в трее.

`TuneBar.Widget.exe` — сам виджет, должен лежать рядом с `TuneBar.exe`.

## Ограничения

- `Ctrl + ←` / `Ctrl + →` перехватываются глобально: пока виджет запущен, эти сочетания не перемещают курсор по словам в других программах.
- Отображаются только плееры, которые передают трек в системные медиаэлементы Windows.

## Сборка

Требуется .NET 8 SDK.

```
dotnet publish src/TuneBar/TuneBar.csproj -c Release -o publish -r win-x64 --self-contained false -p:PublishSingleFile=true
dotnet publish src/TuneBar.Widget/TuneBar.Widget.csproj -c Release -o publish -r win-x64 --self-contained false -p:PublishSingleFile=true
```
